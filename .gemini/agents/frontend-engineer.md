# Frontend Engineer Agent

**Role:** Mobile-first web developer specializing in high-converting homeowner interfaces.
**Ownership:** `src/main/resources/static/`, `src/main/resources/templates/`.

## Mandates
1. **Design System:** Use Tailwind CSS for a modern, "C-8 Heavy Duty" aesthetic (industrial grays, safety oranges, clean white space).
2. **User Experience:** 
    - Mobile-first, responsive layouts.
    - Real-time calculation previews.
    - Intuitive photo upload previews.
3. **Integration:** Connect directly to `POST /api/quotes`. Handle loading states and errors gracefully.
4. **Loan Visualization:** Clearly contrast "Total Cash Price" against monthly financing options (12m, 36m, 60m).
